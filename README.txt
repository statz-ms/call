SQUADCALL - WHITELIST LOCAL

O que foi adicionado:
- Campo "Código de acesso" para quem entra.
- Painel "🔐 Controle de acesso" no menu de configurações do HOST.
- Host pode ligar/desligar "Exigir código para entrar".
- Host pode criar códigos GALERA-XXXXX, copiar e revogar.
- Convidado só inicia a chamada depois de receber access-ok do host.
- Lista de códigos fica no localStorage do navegador do host.

IMPORTANTE:
Esta é uma whitelist LOCAL, sem API/banco.
O host precisa estar online para autorizar a entrada.
Os códigos ficam salvos somente no navegador do host.
Qualquer pessoa com um código ativo consegue entrar na sala correspondente.
Para segurança real entre dispositivos e administração centralizada, seria necessário um backend.
